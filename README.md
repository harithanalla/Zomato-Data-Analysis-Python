# Zomato Data Analysis Using Python

## Project Overview
This project analyzes Zomato restaurant data using Python to identify restaurant trends, customer preferences, ratings, votes, online ordering availability, and approximate cost for two people.

## Objective
The objective of this project is to clean and analyze restaurant data and generate meaningful insights using Python.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Restaurant type distribution
- Votes by restaurant type
- Most voted restaurant
- Online order availability
- Rating distribution
- Approximate cost for two people
- Average rating comparison between online and offline orders

## Key Skills
- Data Cleaning
- Data Analysis
- Data Visualization
- Exploratory Data Analysis (EDA)
- Python Programming

## Project Workflow
Dataset → Data Cleaning → Data Analysis → Visualization → Insights
